# S23 / S25 preferences, themes and diagnostics

Owner-requested combined Settings PR. Phase 0 foundations reused; Adapt, clean-room from Fresnica's established settings/theme/logger contracts. No donor source copied. Capability validates public preferences; a dedicated Realm preferences file stores them across wallet network/session changes without storing images, paths, keys, account balances or logs. App applies them to existing Theme, Localization and native UI providers. No ledger, signing, auth or economic amount policy changes.

- General: light/dark/system appearance and locally selected image palette; language keeps its existing flow. Image picking uses the OS single-image picker, local bounded thumbnail decoding and color extraction; only a validated primary/secondary palette is returned/persisted. Selection cancellation leaves the previous theme unchanged. A capability-owned non-sensitive picker request survives the SessionGate background unmount; a bounded palette waits until foreground and unlocked before saving. Route beforeRemove (including native back/gesture without blur), explicit back/blur, service retirement, replacement requests and intervening preference changes discard stale output. Background privacy and the 30-second lock policy remain enforced. Semantic colors, status/navigation chrome and native UI follow the active appearance with contrast-safe action text.
- Persist display currency (USD/EUR/CNY), haptic feedback, system versus fixed English separators, and Home reserve-panel visibility (default on; available balance and all transaction/reserve calculations remain unchanged). Stellar behavior audit at bd0f4540: XLM/USD used StellarExpert first then CoinGecko; other fiat currencies used CoinGecko, with 60-second caching. Live development probe on 2026-11-12 returned StellarExpert HTTP 402 and CoinGecko anonymous 200 for USD/EUR/CNY. Adapt the public CoinGecko XLM-only display quote via the existing bounded native HTTPS/no-redirect transport, a 60-second memory cache and 5-minute provider freshness checks. Official Demo docs require an API key, so anonymous access is best effort, not a service guarantee; 401/402/429/offline fail visibly without blocking wallet functions. No API keys, accounts, wallet addresses, XDR or balances are sent. No StellarExpert fallback is shipped based on its failed probe. Mainnet Home shows approximate XLM-only fiat value, never a whole-portfolio value or Testnet price; General shows a one-XLM quote. No ledger quantity/input/MAX/signature uses fiat. Exact decimal BigInt display math preserves existing transaction strings.
- Haptic preference governs existing app button/confirm feedback at composition/presentation boundaries, never transaction policy. System number separators retain the full runtime-resolved device region (for example de-CH), independently of supported UI translations; disabling them selects English separators. Formatting stays display-only; input parsing and exact string economic amounts remain unchanged.
- Advanced: Developer Mode retains existing warning/confirmation behavior. Only while enabled, open a bounded sanitized session event viewer with explicit refresh, clear and OS share/export. Export only timestamp/level/validated event codes plus session identity; omit details/caller correlation IDs entirely. No automatic upload, raw exception dumping, wallet state export or new logger. Diagnostics include version/platform/active-network/node status only from existing safe public data.
- Settings load/save/pick/export errors are visible and retryable. Preferences survive restart/network changes. Corrupt/unknown persisted values fall back to validated defaults, never affect keys. Disabled Developer Mode closes pending log/export affordances.

Automated validation covers validators, persistence/reopen, semantic themes/contrast, exact number formatting and UI cancellation/failure paths. Native theme picker and clipboard/privacy/large-text/screen-reader acceptance are separate from helper tests and native compilation. No L4 promotion.
