A wrong passphrase, cancel, background, route/session change, account/signer mutation, pending/uncertain transaction, active protected provisioning, or pending mnemonic backup leaves the signer attached. Unsupported hardware, external and ambiguous/multisigner configurations have no downgrade action in this slice.
